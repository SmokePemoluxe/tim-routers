# tim-routers

Удалённое управление парком роутеров OpenWrt с [podkop](https://github.com/itdoginfo/podkop):
сторож интернета на каждом роутере, агент для связи с сервером и веб-панель, в которой видно
состояние всех роутеров и настраиваются секции podkop.

| Папка | Что там |
|---|---|
| `router/install.sh` | Установка одной командой: podkop (если нет), сторож, агент |
| `router/inet-watchdog.sh` | Сторож интернета: перезапуск WAN/podkop, перезагрузка при сбоях, страница в LuCI |
| `router/tim-agent.sh` | Агент: состояние роутера на сервер, смена ключей, списки, секции, обновления |
| `server/` | Сервер на PHP 8.1+ (SQLite): API для роутеров и веб-панель |
| `tools/` | Диагностика роутера и имитация роутера для проверок |

## Установка на роутер

Зайти на роутер по SSH и выполнить одну команду (готовую, с адресом сервера, показывает панель —
«Как подключить роутер»):

```sh
wget -O /tmp/tr-install.sh https://raw.githubusercontent.com/SmokePemoluxe/tim-routers/main/router/install.sh && sh /tmp/tr-install.sh АДРЕС-СЕРВЕРА
```

Установщик:
1. ставит `curl` и `jsonfilter`, если их нет;
2. ставит podkop официальным установщиком, если его нет (флаг `--no-podkop` — не ставить),
   и переключает DNS podkop на DoH 1.1.1.1;
3. скачивает и проверяет скрипты из этого репозитория (`--ref тег` — конкретная версия);
4. ставит сторожа и агента.

Адрес сервера в скрипты не зашит — он передаётся только при установке.
После установки роутер появляется в панели в «Ждут подтверждения»; без подтверждения он ничего не получает.

## Сторож интернета (inet-watchdog)

Раз в 30 с проверяет связь, DNS роутера, память и LuCI; раз в 3 мин — podkop (его диагностика и то,
что домены из секций получают подменные адреса). Нет связи — перезапуск WAN и podkop; не помогло —
перезагрузка (после 3 подряд — не чаще раза в 30 мин). После перезапуска podkop на несколько секунд
переподключает LAN и Wi-Fi, чтобы устройства забыли «прямые» адреса. Страница в LuCI: **Службы → Сторож интернета**.

## Агент (tim-agent)

Раз в 2 мин отправляет на сервер состояние роутера (модель, версии, MAC, память, каждая секция podkop
с задержкой через clash API sing-box) и забирает задачи. Агент **не выполняет произвольные команды**:
только смена ключа, домены и списки, создание/удаление секций, настройки DNS, отчёт и обновление
скриптов — всё с проверкой входных данных. Новый ключ проверяется; не заработал — возвращается прежний.
Изменения применяются мягким reload podkop. Обновления скриптов берутся только из этого репозитория;
сервер может лишь выбрать версию.

| Команда на роутере | Что делает |
|---|---|
| `tim-agent status` | сервер, регистрация, проверка секций прямо сейчас |
| `tim-agent sync` | выйти на связь немедленно |
| `inet-watchdog test` / `status` | проверка и история сторожа |

## Сервер и веб-панель

PHP 8.1+ с `pdo_sqlite` и `curl`. Скопировать `server/` на хостинг (лучше в папку с неочевидным именем),
`config.sample.php` → `config.php` и заполнить, раз в 5 мин вызывать `cron.php?key=…`.

В панели (работает и с телефона):
- обзор роутеров, уведомления о сбоях и пропаже связи, подтверждение новых роутеров;
- страница роутера: секции podkop (тип, ключ, свои домены и подсети, готовые и внешние списки,
  порядок, **цепочки «секция через секцию»**), DNS, отчёт, обновление скриптов, удаление.

Цепочки: сайт переводит ключ-ссылку (hy2, vless, trojan, ss, socks5) в outbound sing-box с `detour`;
у hy2 сохраняется смена портов (`mport`), которую podkop из ссылок выбрасывает.

Ключи в базе сервера не хранятся после применения.

## Локальный запуск сервера

`start-local.cmd` (Windows; PHP в `C:\Users\Public\tim-routers\php`) — панель на http://127.0.0.1:8080.
С параметром `fake` — ещё и имитация роутера для проверок.
