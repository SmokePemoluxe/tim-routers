# tim-routers — скрипты для роутера

Здесь лежит **весь код, который сервис устанавливает и запускает на вашем роутере** OpenWrt.
Он открыт, чтобы любой мог проверить, что делает роутер и какие данные отправляет.
Код сайта и сервера закрыт и в этот репозиторий не входит.

| Файл | Что делает |
|---|---|
| `router/install.sh` | Установка одной командой: проверяет роутер, ставит podkop (если его нет), сторожа и агента |
| `router/tim-agent.sh` | Агент: сообщает сервису состояние роутера и выполняет ограниченный набор задач (ниже) |
| `router/inet-watchdog.sh` | Сторож интернета: при сбоях перезапускает WAN и podkop, при необходимости перезагружает роутер |
| `tools/diag.sh` | Диагностика роутера для поддержки — запускается только вручную, секреты в выводе скрыты |

Скрипты обновляются **только из этого репозитория**. Сервис может лишь попросить роутер обновиться.

## Что агент отправляет сервису

Раз в 2 минуты:
- модель роутера, версии OpenWrt, podkop, sing-box, агента и сторожа, имя хоста, время работы;
- свободная память и место во флеш-памяти, часовой пояс;
- MAC-адреса роутера (на сервере у роутеров пользователей хранится только необратимый хэш — чтобы узнать переустановленный роутер);
- адрес роутера в локальной сети и внешний адрес от провайдера (у роутеров пользователей сервис их не хранит);
- имена VPN-интерфейсов роутера (для выбора на сайте);
- настройки podkop: секции, их списки доменов и подсетей, тип подключения, адрес сервера прокси (без ключа), задержка через каждую секцию;
- по подписке: названия серверов и их задержки — **без ссылки подписки и без ключей**;
- внешний адрес выхода каждой секции (страна, город, провайдер) — его узнаёт сам роутер у ip-api.com;
- состояние и история сторожа интернета;
- события: входы на роутер (LuCI, SSH, терминал: способ, пользователь, IP и имя устройства в локальной сети) и изменения настроек не через сервис (какие строки изменились — **пароли и ключи заменяются на «СКРЫТО»**).

## Что агент не делает

- **Не выполняет произвольные команды.** Только задачи из короткого списка: изменить секции и списки podkop, сменить ключ, настройки DNS podkop, переключить сервер подписки, прислать отчёт, обновить скрипты или podkop, удалить секцию. Все входные данные проверяются.
- **Не смотрит ваш трафик** и не отправляет историю посещений, списки устройств или содержимое соединений.
- **Не отправляет ссылки подписок и ключи.** Ссылка подписки хранится только на роутере. Ключ, введённый на сайте, передаётся роутеру и на сервере не хранится дольше, чем нужно для применения.
- **Не открывает доступ к роутеру извне.** Агент сам обращается к сервису, входящих подключений нет.

## Если роутер удалён из сервиса или подписка закончилась

- Роутер удалён из кабинета — агент и сторож удаляют себя сами. podkop и его настройки остаются.
- Подписка не активна или нет связи с сервисом больше 30 минут — сторож и автоматика подписок выключаются. podkop продолжает работать с последними настройками.
- Удалить вручную: `tim-agent uninstall` и `inet-watchdog uninstall`.

## Команды на роутере

| Команда | Что делает |
|---|---|
| `tim-agent status` | сервер, регистрация, проверка секций прямо сейчас |
| `tim-agent sync` | выйти на связь немедленно |
| `inet-watchdog status` | состояние и история сторожа |

Страница сторожа в LuCI: **Службы → Сторож интернета** (только просмотр).
